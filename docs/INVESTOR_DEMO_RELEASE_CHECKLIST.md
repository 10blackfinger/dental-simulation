# قائمة مراجعة الإصدار التأسيسي

## الموجود حاليًا
- واجهة عربية باتجاه RTL.
- مساحة عمل ثلاثية الأبعاد لتشريح الفم.
- تحميل نموذج للفكين والأسنان واللثة والتراكيب الأساسية.
- دليل بحث لاختيار التراكيب وعزلها وإظهارها.
- زوايا كاميرا حرة وأمامية وجانبية وعلوية.
- نموذج بديل مبسط عند تعذر تحميل النموذج الخارجي.

## قبل عرض المشروع أو نشره
- التأكد من نجاح فحص JavaScript والبناء واختبارات المتصفح.
- مراجعة التوافق البصري على أحجام الشاشات والأجهزة المستهدفة.
- مراجعة دقة النموذج والمصطلحات بواسطة طبيب أسنان مختص.
- مراجعة الإسناد والترخيص وشروط ShareAlike للنموذج الخارجي.
- اختبار الأداء والذاكرة عند تشغيل النموذج ثلاثي الأبعاد.
- إضافة أي وحدات مستقبلية بشكل مستقل مع اختبارات واعتمادات واضحة.

## حدود الاستخدام

هذه نسخة تأسيسية تعليمية بصرية. لا تمثل محاكاة علاجية مكتملة، ولا تتضمن تفاعلًا سريريًا أو اعتمادًا طبيًا، ولا ينبغي استخدامها للتشخيص أو لاتخاذ قرارات علاجية.
