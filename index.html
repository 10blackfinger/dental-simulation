مساعد طب الأسنان السحابي

اتصال مباشر عبر الإنترنت بخدمة OpenRouter ونماذج متعددة. تحتاج إلى مفتاح API شخصي؛ اكتب المفتاح في هذه الجلسة فقط، ولن يُحفظ في الموقع أو يُرفع إلى GitHub. رسالتك ستُرسل إلى مزود النموذج الذي تختاره، لذلك لا تُدخل أسماء مرضى أو صورًا أو أي بيانات تعريفية.

أنشئ مفتاحًا من صفحة مفاتيح OpenRouter. لا تضع المفتاح في أي ملف برمجي أو رسالة عامة.

أدخل مفتاحك للاتصال
أدخل مفتاح OpenRouter ثم اضغط «اختبار الاتصال». يمكنك اختيار الموجّه المجاني أو نموذج مجاني محدد.
عن الاتصال السحابي والخصوصية

تُرسل الأسئلة إلى OpenRouter ثم إلى مزود النموذج المطلوب عبر اتصال HTTPS. الموجّه المجاني لا يضمن نموذجًا واحدًا ثابتًا، وقد تتغير النماذج والحدود والتوافر. خدمة الاستخدام المجاني محدودة الحصة والسرعة.

مفتاح الخدمة محفوظ في ذاكرة الصفحة فقط، ويُمسح عند تحديثها أو عند الضغط على «مسح المفتاح». إذا كان الاستخدام لمؤسسة أو لعدد كبير من الطلاب، فالأفضل لاحقًا وضع وسيط API آمن على خادم تتحكم فيه المؤسسة مع حدود استخدام ومراقبة وتسجيل موافقات الخصوصية.

المساعد للتعليم ومراجعة المعلومات وليس للتشخيص أو وصف العلاج. راجع الأدلة الأصلية والمشرف المختص، ولا ترسل أي سجل طبي حقيقي.
