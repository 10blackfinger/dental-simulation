# Dental Simulation

مساحة تأسيسية خفيفة لمحاكاة تشريح الفم والأسنان ثلاثي الأبعاد، مبنية باستخدام Vite وBabylon.js.

## ما يتضمنه الإصدار الأساسي

- مشهد ثلاثي الأبعاد مستقل لتشريح الفم.
- نموذج للفكين والأسنان واللثة والتراكيب الأساسية.
- مستكشف بحث لاختيار التراكيب التشريحية وعزلها وإظهارها.
- زوايا كاميرا حرة وأمامية وجانبية وعلوية.
- نموذج بديل مبسط يُنشأ داخل التطبيق عند تعذر تحميل ملف التشريح الأصلي.

## ما أُزيل من الإصدار السابق

أُزيلت جلسة العلاج المتكاملة، مشهد العيادة ومكوناته، الشخصيات ونماذج المرضى، التحكم في الكرسي والمصباح، مكتبة الأدوات والمواد، حركة الأدوات داخل الفم، الأطلس السني المتقدم، أطلس الأسنان اللبنية، أطلس التشريح الكامل، مسارات التدريب وتصدير تقاريرها، ومساعد الذكاء الاصطناعي السحابي والمحلي.

أُزيلت أيضًا تنزيلات وملفات النماذج التابعة لهذه الوحدات. لا يعتمد الإصدار الأساسي على مفاتيح API أو بيانات سرية.

## التشغيل المحلي

يتطلب Node.js 22 أو أحدث واتصالًا بالإنترنت عند تنزيل النموذج لأول مرة.

    npm install
    npm run dev

## الفحص والبناء

    npm run check
    npm run build
    npm run preview
    npm run test:e2e

## النموذج والترخيص

النموذج الخارجي الوحيد في هذه المرحلة هو نموذج تشريح الفم الموثق في [سجل الأصول والتراخيص](public/models/ASSET_CREDITS.md). لا يعني توفر النموذج أو ترخيصه أنه خضع لمراجعة سريرية؛ يجب أن يراجعه مختص قبل استخدامه في تدريس رسمي.
