# Dental Simulation

A browser-based 3D dental learning prototype built with Babylon.js and Vite.

## Current scope
- Procedural 3D clinic room and dental unit.
- Interactive orbit/front/side camera controls.
- Demonstration jaw and tooth meshes.
- Basic chair, dental lamp, and instrument controls.
- No external image assets are overwritten or modified.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Clinical safety
This is an educational visual prototype, not a clinical device or a validated clinical training system. Anatomical models and procedure workflows require review and approval by qualified dental professionals before clinical education use.

## Deployment
The included GitHub Actions workflow builds the static site and deploys it to GitHub Pages. Select **Settings → Pages → Build and deployment → GitHub Actions** if Pages is not already configured.
